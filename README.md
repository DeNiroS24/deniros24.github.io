# Salina Labs Website

Official source repository for the [Salina Labs](https://salinalabs.dev) studio website and product legal documentation hosted on GitHub Pages.

## Directory Structure

* `CNAME`: Domain configuration pointing to `salinalabs.dev`
* `index.html`: Studio homepage and DriveAssist product page
* `404.html`: Custom error page for unmatched routes
* `assets/css/styles.css` / `assets/js/site.js`: Shared design system (dark default + light toggle) and scripts
* `driveassist/`: DriveAssist flagship automotive cockpit platform
  * `support.html`: Support centre and searchable FAQ (includes account-deletion instructions)
  * `privacy.html`: Privacy policy covering on-device speech and cryptographic vault
  * `terms.html`: Terms of service, driver safety waiver, and billing policies
  * `licenses.html`: Open source software notices and third-party library licenses
